Value Plan

A structured tool for tracking project-phase actions designed to build value — from forecast to realised result, not just a line in a budget.

What It Is

Proactive Value Creation, Tracked Properly

Value Plan actions are identified during a project's planning phase and designed to enhance project viability and success rates. Unlike the reactive, incident-driven actions captured in the One Pager, Value Plan actions are proactive by nature — they build the value that justifies the investment in the first place.

The tool exists because good intentions aren't enough: forecasted gains are routinely overestimated, and the leakage that erodes them is routinely underestimated — not through dishonesty, but through the cognitive bias that comes with proximity to your own operations.

"Value plan actions are overestimated and leakage underestimated — not through dishonesty, but through the cognitive biases that come with proximity to your own operations."

How It's Used
  • 1
    Portfolio tracking monitors each action and discontinues efforts once the window of opportunity has closed
  • 2
    Value Driver Trees visualise where value creation occurs and prioritise effort where it has the greatest impact
  • 3
    The EBITDA Bridge converts the plan into a genuine managerial tool, using actual — not budgeted — figures

The Value Plan feeds directly into Process 04 · Action Valuation & Execution and Module 4 · Stabilising Production & Capturing Actions.
